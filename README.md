# All-in-One Toolkit

A free, client-side suite of online tools for common digital tasks, running directly in your browser. No installation needed!

## ✨ Key Features

*   **🖼️ Image Tools:** Photo to PDF, Image Format Converter (JPG, PNG, WEBP, BMP), Image Compressor, and Image Resizer.
*   **🛠️ Utility Tools:** Age Calculator and Unit Converter (Length, Weight, Temperature, Area).
*   **🔳 QR Tools:** QR Code Generator (customizable, downloadable PNG) and QR Code Scanner (camera & image upload).

## 💻 Technologies

*   **Frontend:** HTML5, CSS3 (Bootstrap 5.3, Custom Glassmorphic UI), JavaScript (ES6+)
*   **Libraries:** pdf-lib, FileSaver.js, jsQR, qrcode.min.js

## 🚀 Quick Start

1.  Download `index.html`, `styles.css`, and `script.js`.
2.  Open `index.html` in your web browser.
3.  Use the navigation bar to select and use your desired tool.

## 🎨 Highlights

*   **Glassmorphic UI:** Modern and visually appealing.
*   **Client-Side Processing:** Enhances privacy as files are processed in your browser.
*   **Responsive Design:** Works on desktops, tablets, and mobiles.
*   **User-Friendly:** Intuitive controls and immediate feedback.

## ⚠️ Important

Remember to update placeholder URLs in `index.html` (for domain, social media images, and site search) before deploying.
